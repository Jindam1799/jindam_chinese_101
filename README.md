# 진담 100문장 툭!

진담중국어 클래스101 강의 《중국어, 외웠는데 왜 말이 안 나올까?》의 복습·말하기 훈련 웹게임입니다.

- 4주 20강 · 16상황 · 목표 문장 100개
- 오늘의 학습: ① 덩어리 맞추기(덩어리훈련 방식, 단계별로 늘려 가기) → ② 보고 말하기 → ③ 내 문장 툭!
- 다시 툭!(간격 반복 복습) · 강의 목록 · 성장 기록(Before & After)
- 진담체육관에서 훈련하는 마음싹, 힐링 배경음악, 중국어 음성(Tingting 여자 목소리 우선)

## 실행
`index.html` 한 파일로 동작합니다. GitHub Pages(Settings › Pages › Branch: main / root)로 바로 배포할 수 있습니다.

## 기록 저장
로그인 없이 브라우저(localStorage)에 저장됩니다. 기기를 바꿀 때는 설정 › 백업 코드를 이용하세요.

## 문장 데이터
`index.html` 안의 `LESSONS`(100문장)와 `STAGES`(덩어리훈련 단계)는 검수 전 초안입니다. 검수 후 이 두 부분만 바꾸면 게임 전체에 반영됩니다.
